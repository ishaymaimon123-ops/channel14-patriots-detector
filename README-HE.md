# זיהוי פרסומות הפטריוטים — פריסה ל־blitz.cloud

חבילת פריסה של המערכת הקיימת. המערכת מקבלת קישור HLS או קובץ, מזהה מקבצי פרסומות, ומחברת את כל הפרסומות שזוהו לסרטון MP4 אחד לצפייה ולהורדה.

`Dockerfile` מתקין FFmpeg ו־Tesseract עם עברית, מריץ את האתר בפורט 8080 כמשתמש ללא הרשאות root, ושומר תוצאות בתיקיית `/app/work` המתמידה בין הפעלות ב־blitz.cloud.

המסלול החינמי של blitz.cloud נמצא בבטא. לפי התיעוד הנוכחי הוא ללא כרטיס וללא מגבלת זמן, עם 10 GB אחסון; ייתכן שהתנאים ישתנו. תמונות Docker מוגבלות ל־512 MB זיכרון בפועל, ולכן סריקות ארוכות וייצוא וידאו רבים עלולים להיתקל במגבלה. קבצים הנשמרים בתיקייה המתמידה אינם מגובים אוטומטית. הורידו תוצאות חשובות.

הקוד והתבניות אינם מכילים קישור שידור, סיסמה או קובצי וידאו שהועלו. אם מפרסמים את המאגר ב־GitHub ציבורי, אין לכלול בו את תיקיית `work`.
